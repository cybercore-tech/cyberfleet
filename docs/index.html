01 / The bar

One number.
Zero waiting.

The widget refreshes every 60 seconds from a local-only scan — no network fetch runs automatically, so your bar never blocks on a slow or offline remote. First launch finds your dev folders on its own: Devspace, projects, code, .sysops, repos and more.

03 / Setup

Muster
the fleet.

One command installs the widget and the manager binary. A bundled linux-x86_64 binary ships with the plugin; elsewhere it builds this same checkout with cargo build --locked — it never downloads and runs a prebuilt artifact from the network.

INSTALL / REMOVE 
omarchy plugin add https://github.com/cybercore-tech/cyberfleet.git --enable

# remove
omarchy plugin remove io.github.darkstardevx.cyberfleet
~/.config/cyberfleet/config.json 
{
  "roots": ["~/Devspace", "~/.sysops"],
  "ignore": ["node_modules", "target", "vendor", ".cache"],
  "max_depth": 4
}
